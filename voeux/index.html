Publier sur GitHub

Le fichier de cette animation vient d’être téléchargé. Il reste à le déposer sur GitHub :

  1. Ouvrez la page de dépôt sur GitHub et connectez-vous si nécessaire.
  2. Choisissez dans vos téléchargements le fichier . S’il a déjà été téléchargé, vérifiez que son nom est exactement celui-ci, sans numéro ajouté.
  3. Sur GitHub, validez avec le bouton « Commit changes ». Si le fichier existe déjà, son remplacement actualisera le même lien.

Après la validation, ouvrir le lien de l’animation. L’actualisation peut prendre quelques minutes.
