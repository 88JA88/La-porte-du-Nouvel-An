# Futures animations

Ce dossier est réservé aux animations de vœux destinées à être publiées plus tard. Aucune animation n'est incluse pour le moment.

Pour préparer une animation, utiliser l'éditeur local et son export HTML ou son export de publication. Ajouter ici uniquement le fichier HTML choisi pour la publication, sous un nom distinct pour chaque destinataire. Plusieurs pages pourront ainsi coexister dans ce même dépôt.

Conserver sur l'ordinateur les sauvegardes JSON et le fichier de correspondance des destinataires ; ne pas les déposer ici. Une fois GitHub Pages configuré pour servir ce dossier depuis la racine du site, chaque fichier aura sa propre adresse sous `voeux/`.

GitHub Pages n'est pas encore activé. La disponibilité de Pages dépend notamment de la visibilité du dépôt et de l'offre GitHub. Une page publiée est accessible sur Internet ; un nom difficile à deviner ne constitue pas une protection par mot de passe. Dans un dépôt public, les noms et le contenu des fichiers, ainsi que leur historique, sont également visibles.
